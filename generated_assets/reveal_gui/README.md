# Reveal GUI Assets

These transparent PNGs are generated by Blender for the egg-opening NPC reveal GUI.

## Regenerate Assets

From the repository root, run:

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background --python .\tools\generate_reveal_gui_assets.py
```

The script writes PNGs to:

```text
generated_assets/reveal_gui/
```

## Upload To Roblox

Upload these PNGs as image assets in Roblox:

- `soft_radial_glow.png`
- `rarity_burst_ring.png`
- `sparkle_star.png`
- `shine_streak.png`
- `reveal_podium.png`
- `reveal_card_glow.png`
- `egg_crack_flash.png`
- `new_badge.png`
- `tap_to_continue_panel.png`

Paste the resulting Roblox image IDs into:

```text
src/StarterPlayer/StarterPlayerScripts/NPCRevealAssets.lua
```

The reveal still runs with code-created fallbacks while these IDs are placeholders.

## Game Hook

`src/StarterPlayer/StarterPlayerScripts/ZoneEggHatchClient.client.lua` listens to the existing egg-opening remotes:

- `ReplicatedStorage.Remotes.EggRevealResult`
- `ReplicatedStorage.Remotes.StartNPCReveal`
- `ReplicatedStorage.ZoneEggHatchResult`

Those payloads are passed into:

```lua
RevealNPC.show({
	npcName = "Brr Brr Patapim",
	rarity = "Legendary",
	isNew = true,
	eggType = "Rare",
	npcImage = "rbxassetid://PASTE_NPC_IMAGE_ID",
})
```

The reveal flow is: egg bounce, shake, glow, crack flash, burst ring, sparkles, NPC reveal, rarity/name text, optional NEW badge, tap to continue, then cleanup.
