\# AGENTS.md



This is a Roblox brainrot hide-and-seek / capture simulator game.



Important rules:

\- Use Luau / Roblox Studio-compatible code.

\- Prefer full script replacements over tiny patches.

\- Do not create duplicate patch scripts unless necessary.

\- Before editing, identify which existing scripts control the same system.

\- Preserve the current game structure unless a change is clearly needed.

\- Be careful with:

&#x20; - BrainrotCore

&#x20; - PlotService

&#x20; - placement prompts

&#x20; - inventory tools

&#x20; - collect money systems

&#x20; - save/load systems

&#x20; - tutorial arrows

&#x20; - capture systems

\- Do not break existing player data.

\- Do not assume Rojo can sync models, terrain, meshes, or map objects yet.

\- This repo currently manages scripts only.



Main product goal:

Make the first 5 minutes clean and addictive:

capture Brainrot -> get tool -> place on own plot -> NPC appears -> earns money -> collect money -> upgrade/return.



When changing code:

1\. Explain the plan first.

2\. Mention which scripts should be disabled.

3\. Create clean replacement scripts.

4\. Avoid stacking more temporary repair scripts.
