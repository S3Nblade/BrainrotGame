# Icon Exports

The Blender generator renders one transparent 512x512 PNG per starter Brainrot.

Expected names use the AssetIds key, for example:

- `WobbleNugget.png`
- `GoofyCone.png`
- `CosmicBrainFrog.png`

After upload, paste IDs into `AssetIds.Icons`.
Rendered Brainrot thumbnails/icons go here before upload to Roblox.
